Грузоотправитель создаёт ЭТрН
Заполняет сведения о перевозке
Подписывает титул 1
Отправляет титул 1 перевозчику через оператора ЭДО
Перевозчик получает титул 1
Проверяет данные
Принимает груз к перевозке
Формирует и отправляет титул 2
Водитель начинает перевозку
Грузополучатель получает уведомление
Проверяет груз
Подтверждает приём груза
Формируется титул 3
Перевозчик завершает перевозку
Формируется титул 4
Процесс завершается

4. Boundary Values (граничные значения)
4.1 Вес груза (пример логики XSD/бизнеса)

0 кг → минимально допустимое
0.1 кг → минимально валидное
19 999 кг → валидное значение
20 000 кг → верхняя граница
20 001 кг → невалидное значение
-1 кг → невалидное значение

4.2 Объём груза

0 м³ → минимальное
0.01 м³ → валидное
81.99 м³ → валидное
82 м³ → верхняя граница
82.01 м³ → невалидное
-0.1 м³ → невалидное

4.3 Длина строковых полей (пример)

1 символ → минимальное
maxLength - 1 → валидное
maxLength → валидное
maxLength + 1 → невалидное

4.4 Количество мест / паллет

0 → граничное
1 → минимально валидное
max → допустимое
max + 1 → ошибка
