# README — Блок 1: Тестирование требований (ЭТрН)

---

## 1. Анализ бизнес-процесса

### 1.1 Участники процесса

- Грузоотправитель
- Оператор ЭДО
- Перевозчик
- Водитель
- Грузополучатель

---

### 1.2 Основные статусы ЭТрН

- Черновик
- Подписан грузоотправителем
- Отправлен перевозчику
- Получен перевозчиком
- Принят к перевозке
- В процессе перевозки
- Доставлен
- Принят грузополучателем
- Завершен

---

### 1.3 Основной бизнес-процесс (Happy Path)

- Грузоотправитель создаёт ЭТрН
- Заполняет сведения о перевозке
- Подписывает титул 1
- Отправляет титул 1 перевозчику через оператора ЭДО
- Перевозчик получает титул 1
- Проверяет данные
- Принимает груз к перевозке
- Формирует и отправляет титул 2
- Водитель начинает перевозку
- Грузополучатель получает уведомление
- Проверяет груз
- Подтверждает приём груза
- Формируется титул 3
- Перевозчик завершает перевозку
- Формируется титул 4
- Процесс завершается

## 3. Проверки по XSD-схеме (структурные ограничения)

---

### 3.1 Обязательные элементы

- ИдФайл
- Документ
- СвГруз
- СвГО
- СвПрв
- СвГП

---

### 3.2 Ограничения данных

- minLength / maxLength строковых полей
- totalDigits числовых полей
- fractionDigits decimal полей
- use="required" обязательные атрибуты
- use="optional" необязательные атрибуты

---

### 3.3 Бизнес-правила внутри XSD

#### СвКонтейн

- КолПломб обязателен при наличии НомПломб
- НомПломб обязателен при наличии КолПломб

#### ПодпИнфПрв

- СвДоверЭл обязателен при СпосПодтПолном = 3
- СвДоверБум обязателен при СпосПодтПолном = 5

#### ИдФайл

- имя файла должно соответствовать значению ИдФайл

---

### 3.4 Типы данных

- xs:string
- xs:integer
- xs:decimal
- ДатаТип / ВремяТип
- ограничения точности и диапазонов

## 4. Boundary Values (граничные значения)

---

### 4.1 Вес груза

- 0 кг → минимально допустимое значение
- 0.1 кг → минимально валидное значение
- 19 999 кг → валидное
- 20 000 кг → верхняя граница (валидно)
- 20 001 кг → невалидное
- -1 кг → невалидное

---

### 4.2 Объём груза

- 0 м³ → минимальное
- 0.01 м³ → валидное
- 81.99 м³ → валидное
- 82 м³ → верхняя граница (валидно)
- 82.01 м³ → невалидное
- -0.1 м³ → невалидное

---

### 4.3 Длина строковых полей

- 1 символ → минимальное
- maxLength - 1 → валидное
- maxLength → валидное
- maxLength + 1 → невалидное

---

### 4.4 Количество мест / паллет

- 0 → граничное значение
- 1 → минимально валидное
- max → допустимое
- max + 1 → ошибка

## 6. Баг-репорты

---

### BUG-001

**Заголовок:**  
Система позволяет отправить ЭТрН без обязательных реквизитов грузополучателя

**Шаги воспроизведения:**
1. Создать ЭТрН
2. Не заполнить данные грузополучателя
3. Подписать документ
4. Отправить документ

**Фактический результат:**  
Документ успешно отправлен

**Ожидаемый результат:**  
Система блокирует отправку до заполнения обязательных данных

**Severity:** Critical  
**Priority:** P0  

---

### BUG-002

**Заголовок:**  
Возможен переход в статус «Принят грузополучателем» до завершения перевозки

**Шаги воспроизведения:**
1. Создать ЭТрН
2. Перевести в статус «Принят к перевозке»
3. Не завершать перевозку
4. Подтвердить получение груза

**Фактический результат:**  
Статус изменён

**Ожидаемый результат:**  
Переход запрещён до завершения перевозки

**Severity:** Critical  
**Priority:** P0
