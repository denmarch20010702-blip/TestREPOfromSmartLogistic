# Traceability Matrix — ЭТрН (Block 1)

Цель: связать XSD структуру с тестовыми проверками.

---

## 1. СвГруз (Сведения о грузе)

| XSD элемент | Проверки |
|------------|----------|
| СвГруз | наличие секции, корректная вложенность |
| ОпГруз | наличие минимум 1 записи |
| НаимГруз | min/max length, пустое значение |
| ВесГрузБрут | диапазон, decimal precision, отрицательные значения |
