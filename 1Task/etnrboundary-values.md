# Boundary Values — ЭТрН

## 1. Вес груза (ВесГрузБрут)

- 0 кг → минимальная граница (нужно уточнение бизнес-логики)
- 0.01 кг → минимально допустимое значение
- 19 999.99 кг → валидное значение
- 20 000 кг → максимум
- 20 000.01 кг → ошибка
- -1 кг → невалидное значение

---

## 2. Объём груза

- 0 м³ → граничное
- 0.01 м³ → валидное минимальное
- 81.99 м³ → валидное
- 82 м³ → максимум
- 82.01 м³ → ошибка

---

## 3. Строковые поля (НаимГруз)

- 1 символ → минимум
- 255 символов → максимум
- 256 символов → ошибка
- пустая строка → ошибка

---

## 4. Даты

- текущая дата → валидно
- +1 день → валидно
- вчера → ошибка

---

## 5. Количество мест

- 0 → зависит от логики
- 1 → валидно
- max int → boundary
