# QA тестовый проект

## Описание проекта

Данный репозиторий содержит выполнение тестового задания на позицию QA Engineer.

Проект демонстрирует практический QA workflow: анализ требований, проектирование тестов, API тестирование, работа с SQL, XSD-валидацией, а также применение AI-инструментов для генерации и анализа тест-кейсов с последующей критической оценкой.

## Цель проекта

Показать навыки:
- анализа бизнес-требований
- проектирования тестовой документации
- применения техник тест-дизайна
- тестирования REST API на основе индустриальных стандартов
- написания SQL-запросов (PostgreSQL)
- работы с XSD схемами и структурной валидацией данных
- критического анализа результатов LLM

---

## Структура репозитория

### /1Task — ЭТрН: требования и тестирование

Содержит полный разбор электронной транспортной накладной (ЭТрН):

- анализ бизнес-процесса
- описание жизненного цикла документа
- чек-листы тестирования
- негативные сценарии
- баг-репорты
- XSD-валидация и структурные ограничения
- boundary values (граничные значения)
- traceability matrix (связь XSD → тесты)

Дополнительно:
- `xsd shemes` — исходные XSD-схемы
- `etrn-process.png` — схема бизнес-процесса
- `etnrboundary-values.md` — граничные значения
- `etnrtraceability-matrix.md` — трассировка XSD → тесты

---

### /2Task — AI Prompt Engineering & Review

Содержит работу с LLM:

- промпт для генерации тест-кейсов
- сырой ответ модели
- анализ и ревью результата
- выделение ошибок и упущений LLM
- boundary values для формы заявки

---

### /3Task — SQL задачи (PostgreSQL)

Реализованы SQL-запросы:

- вторая по величине уникальная зарплата
- поиск дублирующихся email
- клиенты без заказов

---

### /4Task — тестирование REST API

Содержит анализ API `/api/v2/orders`:

- поддерживаемые HTTP методы
- ожидаемые статус-коды
- позитивные и негативные сценарии
- обработка ошибок и edge cases
- соответствие REST API best practices (Google / Microsoft guidelines)

Дополнительно:
- `api.md` — исходное описание API из задания

---

## Примечания

Проект построен с использованием следующих подходов:

- техники тест-дизайна: классы эквивалентности, граничные значения, переходы состояний
- негативное тестирование
- проверка бизнес-логики и ограничений данных
- структурная валидация (XSD)
- анализ API по индустриальным стандартам
- использование AI для генерации тест-кейсов с последующей валидацией
