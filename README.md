Описание проекта

Данный репозиторий содержит выполнение тестового задания на позицию QA Engineer.

Проект включает в себя анализ бизнес-требований, проектирование тестов, работу с XSD-схемами, API тестирование, SQL задачи и применение AI-инструментов для генерации и анализа тест-кейсов.

Цель проекта — продемонстрировать навыки анализа требований, тест-дизайна, работы с API и базами данных, а также способность критически оценивать результаты, полученные с помощью LLM.

Структура репозитория

/1Task
README.md — содержит выполненое задание по тестированию требований электронной транспортной накладной (ЭТрН), включая бизнес-процесс, чек-листы, XSD проверки, негативные сценарии, баг-репорты, boundary values и traceability matrix
Дополнительно:
xsd shemes — сожержит исходные .xsd файлы проекта
etrn-process.png — графическое изображение схемы проекта

/2Task
1 README.md — Краткое описание выполненого задания
2 prompt.md — Промпт использовавшийся для генерации ответа LLM
3 ai-responce.md — Сырой ответ LLM модели на заданный промпт
4 review.md — Анализ ответа LLM модели
5 boundary-values.md — файл с граничными значениями и критическими кейсами

/3Task
README.md — чек-лист тестирования REST API /api/v2/orders, анализ HTTP методов, статусов, негативных сценариев и соответствие API guidelines
Дополнительно:
api.md — Исходный файл приложенный к заданию с описанием работы API
